### 1. Проектирование

##### Оценка сложности и масштаба приложения

Mesto –  приложение обмена фотографиями.

Функциональность:

- Загрузка фотографий.
- Удаление фотографий.
- Отображение списка фотографий.
- Сбор и учёт лайков под фотографиями.
- Создание профиля пользователя и его редактирование.
- Аутентификация и авторизация пользователей.

Приложение состоит из двух основных частей: Front-end (клиентская часть) и Back-end (серверная часть).

Front-end часть
- Исходники располагаются в каталоге `frontend/src`
- Веб-приложение.
- Монолитный фронтенд.
- Проект структурирован по методологии БЭМ.
- Используется фреймворк React.

Приложение тривиально, но имеет колоссальную популярность среди пользователей. Входе сложных следований выявлено, что в ближайшем будущем ожидается прирост числа пользователей, что может создать некоторые проблемы с производительностью. Вертикальное масштабирование достигло своей верхней границы как по финансам организации так и по тех. возможностям современных вычислительных систем)) Над проектом работает команда состоящая из огромного числа сотрудников, что создает проблемы при совместной разработке и поддержке текущего продукта. Техническим руководством было принято решение о переходе клиентской части на микрофронтенды.

#### Опыт команды

- Команда имеет опыт построения компонентной архитектуры.
- Знакома c практиками предметно ориентированного проектирования (Domain-Driven Design).
- Имеет опыт работы с практиками и инструментами для реализации микрофронтендов, а частности Webpack Module Federation.

Выбирая между SPA и Module Federation был выбран 2-ой инструмент так как команды уже работали с ним и нет необходимости в использовании различных на каждый компонент фронтенд фреймворков.

Это позволяет легко масштабировать, поддерживать и развивать проект в будущем.
